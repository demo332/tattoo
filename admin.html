Relier l’admin à GitHub

À faire une seule fois par appareil. Le jeton reste chiffré dans ce navigateur, protégé par ton code.

Comment créer le jeton ?
  1. GitHub › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Repository access : Only select repositories › ton dépôt du site.
  3. Permissions › Repository permissions › Contents : Read and write. Rien d’autre.
  4. Génère, copie le jeton et colle-le ici.
